# CodeCommerce

A production-ready full-stack e-commerce platform built with React, Node.js, Express, and MongoDB.

## Live Demo

- Frontend: https://commerce-core-frontend.vercel.app
- Backend API: https://commerce-core-backend.vercel.app/api/health

## Tech Stack

### Frontend
- React.js
- Vite
- Redux Toolkit
- Axios
- Bootstrap

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- JWT Authentication
- Cloudinary
- Razorpay

### Deployment
- Vercel

## Features

### Customer Features
- Register and login
- Browse products
- Add to cart and wishlist
- Checkout with Razorpay
- Order tracking
- Reviews and ratings

### Admin Features
- Dashboard with analytics
- Manage products
- Manage orders
- Manage users
- Manage categories
- Moderate reviews
- Reports and settings
